# Day-of-week and month names in European languages, added 2026-09-17
# after real casework: an Android locale/calendar-picker resource-dump
# file (one file, "CASEFILE.txt") contributed 32 of 276
# accepted names in a real case scan, nearly all calendar words in
# German/French/Spanish/Italian/Polish/Swedish/Portuguese/Dutch (Jan,
# Sep, Juni, Maj, Lundi, Januar, Juli, Freitag, Ene, Sobota...) that
# cleared the ML-confidence-only corroboration path on repetition +
# isolated-line shape alone (see decision_engine.py's
# _is_common_word_phrase / common_words guard - same mechanism that
# already stops "Vice President"/"Convertible Debt").
#
# Public-domain factual vocabulary (basic calendar terminology, not
# copyrighted creative content) - same licensing posture as
# common_english_words.txt. Loaded into the same `common_words`
# frozenset (see knowledge_base.py), so this only ever blocks the
# ML-confidence-ALONE corroboration path - a genuine person whose name
# happens to match a calendar word (e.g. "Domingo", "Julio", "Avril",
# "Mayo" are all real given names in some cultures) still reaches
# ACCEPTED normally via dictionary/title support, exactly like any
# other ambiguous-word case in this project.
#
